# Контент и маркетинг в Cursor

## Простыми словами

Cursor — не только для программистов. В папке с текстами, лендингами и заметками Agent помогает писать, структурировать и править материалы так же, как редактор в Google Docs — только с diff и контролем.

## Когда вам это нужно

- Пишете посты, статьи, письма, лендинги
- Нужна SEO-структура или контент-план
- Хотите единый tone of voice через rules
- Собираете отчёт для команды в Canvas

## Какой режим выбрать

| Задача | Режим | Почему |
|--------|-------|--------|
| «Что тут за файлы?» | Ask | Ничего не меняет |
| Один пост или письмо | Agent | Быстрый черновик в файл |
| Лендинг из 5+ блоков | Plan | Сначала план, потом тексты |
| Сломался сайт после правки | Debug | Ищет причину |
| Отчёт с визуалом | Agent + Canvas | Удобно показать коллегам |

## Пошагово (первый раз)

1. Создайте папку, например `контент-проект`, откройте в Cursor
2. **Ask**: «Объясни структуру папки, ничего не меняй»
3. **Agent**: «Черновик поста на тему X, сохрани в drafts/»
4. Откройте diff — зелёное новое, красное удалённое
5. Примите или отклоните правку
6. Если пишете часто — попросите главного Agent создать **rule** со стилем

## Аналогии

- **Ask** — редактор читает бриф, ничего не трогает
- **Agent** — копирайтер пишет черновик в вашем документе
- **Plan** — сначала оглавление лендинга, потом тексты по разделам
- **Rule** — гайд по tone of voice на стене редакции

## Частые ошибки

- Просите «сделай лендинг» в Agent без плана — получите хаос в файлах
- Не смотрите diff — Agent может переименовать не тот файл
- Путаете папку с кодом сайта и папку с текстами — откройте отдельную папку для контента
